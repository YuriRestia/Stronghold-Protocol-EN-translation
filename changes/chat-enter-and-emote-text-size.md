## 2026-11-12

### Room chat: Send and the emote button at the chat's text size

- In the room screen's chat (team rooms and Grand Alliance rooms), the Send button's label is now as big as the chat's
  own text, and the button is as tall as the message box. The emote button's icon grows with it, and the ⤢ / ⤡
  button that grows the chat is as big as the emote button, with a larger arrow.
- Before: Send used the small button text (about 12 px on a desktop, about 6 px in the phone chat sheet) and the emote
  icon stayed 16 px, so both looked tiny next to the chat. Both follow the Text Size setting like the rest of the chat.
