  the next sync can be a plain `git merge`.
- 38 files conflicted: 24 goldens, 3 generated data files, 11 code / doc / test files resolved by hand.

  - `public/js/ui/stats.js`, `test/ui/stats.test.js`, `server/match/player/items.js`: both sides' imports / checks.
  - `server/match/botWorld.js`: our lobby-rule fields and Yuri's `oneForAll`.

    moments and impacts.
